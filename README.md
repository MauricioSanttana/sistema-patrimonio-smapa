# Sistema de Controle Patrimonial - SMAPA

Sistema de gestão patrimonial desenvolvido pela Secretaria Municipal do Meio Ambiente e Proteção Animal de Mogi das Cruzes - SP.

## 🎯 Funcionalidades

- ✅ Controle completo de patrimônio
- ✅ Busca avançada por múltiplos campos
- ✅ Filtros por categoria
- ✅ Exportação para Excel
- ✅ Relatórios automáticos
- ✅ Controle de localização e responsáveis
- ✅ Interface responsiva

## 🚀 Como Usar

1. Use os filtros para localizar itens específicos
2. Clique em "Ver" para detalhes completos
3. Exporte relatórios em Excel ou TXT

## 📊 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- SheetJS (exportação Excel)
